# European Digital Engagement

## Project Overview
This project examines online public-service engagement and online news consumption among young Europeans aged 16–24.

## Data Sources
- **Kaggle:** Europeans Using Online Public Services (2008–2025).
- **Eurostat:** Internet use – reading online news sites and newspapers.

## Methods
The project uses Python and pandas to acquire, clean and merge datasets. Seaborn and Matplotlib are used to explore patterns through visualisations.

## Analysis
The merged dataset contains 2,989 observations across 37 countries. The analysis covers 2013–2025.

The correlation between online news consumption and average online public-service engagement is 0.515.

## Limitations
The data are aggregated at country level, so results cannot establish individual-level behaviour or causation. Some country-year observations are missing.
