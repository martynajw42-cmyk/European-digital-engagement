# AI Usage Report

ChatGPT was used as an AI assistance tool during this data acquisition project.

## How AI was used
- Assistance with identifying and understanding suitable datasets.
- Guidance on retrieving data from the Eurostat API.
- Help writing and debugging Python code in Google Colab.
- Assistance with cleaning, filtering and merging datasets using pandas.
- Guidance on creating visualisations using Seaborn and Matplotlib.
- Support interpreting statistical results and identifying limitations.
- Assistance preparing project documentation.

## Student responsibilities
I selected and reviewed the datasets, executed the code, checked the outputs, interpreted the results and made decisions about the analysis.

AI-generated suggestions were reviewed and adapted as necessary.
## prompts used

The following are examples of prompts used to assist with the project:

1. "How do I import a CSV dataset from Kaggle into Python using pandas?"
2. "How can I check my dataset for missing values and understand its columns?"
3. "How can I retrieve complementary data from the Eurostat API using Python?"
4. "How do I clean and merge two datasets using country and year as common columns?"
5. "How can I create visualisations using Seaborn to explore my data?"
6. "How can I calculate and interpret the correlation between two variables in my dataset?"

## What worked well and what didnt 

ChatGPT worked well for helping me write Python code, import datasets, clean and merge data, and create visualisations. It was also useful for explaining unfamiliar code and helping me fix errors when they occurred. However, some of the code did not work correctly straight away and needed to be adjusted to suit my datasets. Some visualisations also needed to be changed to make the results clearer. I learned that AI can be a useful tool for technical assistance, but it is important to check the code, understand what it does and explore the data independently rather than relying on AI to interpret everything.
